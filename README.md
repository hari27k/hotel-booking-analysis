# Hotel Booking, Revenue and Cancellation Analysis

## Project Overview

This project analyzes hotel booking data to understand booking
patterns, cancellations, customer types, ADR, and country-wise
completed bookings.

## Project Parts

### Part 1 – Python & Pandas
- Data understanding
- Data cleaning
- Missing value handling
- Duplicate removal
- Basic analysis

### Part 2 – Web Scraping
- Web scraping using Requests and BeautifulSoup
- External city information

### Part 3 – SQL
- Cancellation percentage
- Monthly bookings
- Average ADR by customer type
- Lead time vs cancellation
- Top 5 countries by completed bookings

### Part 4 – Excel
- Pivot tables
- Cancellation rate
- Average ADR
- Conditional formatting
- Charts
- Summary

### Part 5 – Power BI
- Interactive dashboard
- Booking KPIs
- Cancellation analysis
- ADR analysis
- Country and hotel analysis

## Tools Used

- Python
- Pandas
- BeautifulSoup
- PostgreSQL
- pgAdmin
- Microsoft Excel
- Power BI
- GitHub
